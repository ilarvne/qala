## Actual provider checks

[API readiness](research/api-readiness-2026-10-20.md) distinguishes configured credentials, actual completed operations and remaining balance. All reports omit secrets, signed URLs and raw commercial responses.

- [AlemPlus](../artifacts/alemplus-readiness-2026-10-20.json): five authenticated adapters, real EN/RU/KK grounded graph/rerank runs, two 1,024-dimensional embedding vectors and two real speech-fixture recognitions. Cloud embedding verification does not replace the active local MiniLM index.
- 2GIS: three current exact source lookups returned matched profiles with no-store responses. [Earlier detailed source proof](../artifacts/twogis-source-verification.json) and [22 React lifecycle checks](../artifacts/place-profile-hook-verification.json) have separate scopes. At most three current profiles load after explicit user action; missing/ambiguous ratings are omitted rather than invented.
- ElevenLabs: **16 spoken-language presets** and the language/tool prompt split were applied and read back. [Configuration proof](../artifacts/voice-language-configuration-verification.json) also records private-session issuance, including local French/Arabic/Italian requests. Planner and dictation retain EN/RU/KK; some Kazakh shell controls currently fall back to English. Configuration is not sixteen completed conversations or a pronunciation evaluation. [Research](research/multilingual-voice-2026-10-20.md).
- Existing Russian narration consists of seven actual ElevenLabs takes with word alignments. Earlier private WebSocket evidence includes provider audio and an authenticated planner-tool response. Browser dictation uses synthetic microphone input with actual AlemPlus. Physical human microphone use and a real SIP/Twilio call remain unverified.
- Valhalla, forecast, operator calendar, OpenFreeMap style/TileJSON and an actual Astana vector tile returned valid responses. OpenAI returned HTTP 401, establishing authentication rejection rather than a proven exhausted quota. Google, Yandex, Foursquare and Twilio were not probed without configured access.

The separate [public-card evaluation](research/map-provider-crawl-2026-10-20.md) retains 16 observations, 9 strict matches, 12 ratings and 36 photo-source links. It downloaded no provider photographs and retained no review prose. CAPTCHA/429 stopped public-site acquisition. The authenticated owned-key API is a different access path. Evaluation observations do not enter the open corpus.
