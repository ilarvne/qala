Через Exa выполнены 11 запросов: запрошен 91 результат, получен 81,
после удаления совпадающих URL осталось 64 уникальных адреса. Это поисковая
выборка, а не число подтверждённых заведений. Вторая стадия проверяла конкретные

Поисковые выдачи сами по себе не становились доказательством идентичности.

  где P10689 прямо указывает OSM way 240592107.

Первый поисковый проход Wikidata остановлен после HTTP 429: сохранены десять

отдельно получены небольшие пакетные ответы для уже выбранных конкретных файлов;
сборщик не повторяет ошибочный запрос автоматически. Публичные страницы 2GIS и
Яндекса, ранее остановившие сбор, повторно не запрашивались. Закрытые ответы
коммерческих API не попадали в открытый набор.

## Исправление идентичности

Прежняя редакторская связь приписывала фонтану «Цирк»
`osm-way-1134744434` Wikidata-ID здания цирка Q21843144. Новый контроль типов
отклоняет такую пару даже при совпадающем имени или уже записанном QID.
Убраны только производные QID, алиасы и ссылка на ошибочно сопоставленную
сущность; исходные OSM-теги и первичные поля фонтана не изменены. Фотографии
фонтанов привязаны к фонтану, а не к расположенному рядом зданию цирка.

Также добавлена строгая обратная связь Wikidata → OSM: P10689 для way и P402
для relation. Требуются точный OSM-ID, совместимый физический тип и реальные
координаты сущности не дальше 200 м. Повторяющиеся и противоречащие заявления,
нечисловые ID, неподходящие типы и неизвестные координаты отклоняются. Так
подтверждён Q1899549 для существующего Успенского собора без нечёткого сравнения
русских названий.

## Сбор, публикация и автономная проверка

`scripts/collect_curated_commons.py` принимает только явно названные местные
объекты и точные названия файлов: до 24 POI, до двух файлов на объект и до трёх
пакетных запросов. Между пакетами не меньше десяти секунд. Ошибка HTTP/API
останавливает кампанию без автоматического повтора. Успешные ответы, исходные
времена получения и неизменяемые хеши сохраняются при продолжении. Изображения
получаются только с публичных HTTPS-хостов Wikimedia, до 3 МБ, с проверкой
формата, размеров и декодирования; уже полученные байты не заменяются молча.

Переносимые доказательства находятся в
`data/raw/curated-media-expansion-2026-10-20/`. В них нет полного HTML
оператора, ключей, коммерческих ответов API или текстов пользовательских отзывов.
Исходный HTML остаётся только в закрытом `.local`-кеше; для автономной проверки
достаточно коротких операторских выдержек и сохранённых структурированных данных.

Публикация выполнена командой:

```sh
.venv/bin/python scripts/publish_curated_expansion.py \
  --stage .local/media-expansion-2026-10-20/publish-stage
```

Перед заменой нормализованных файлов сборщик заново компилирует связи из
сохранённых метаданных, проверяет авторство/лицензии/описания/времена/хеши и
выполняет переносимый offline replay. Затем существующий `export_dataset`
публикует JSON, CSV, GeoJSON, манифест, атрибуции и курацию одним набором с
откатом при обработанной ошибке. Сырые доказательства и кеш изображений
остаются отдельными аудит-артефактами; это не crash-atomic хранилище нескольких
файлов. Наличие одних только новых сырых файлов не включает расширение:
нужен опубликованный маркер `metadata.curated_media_expansion`.
После активации каталога исходные доказательства неизменяемы: повторная
публикация с другим содержимым останавливается до любых записей. Для новой
кампании нужен отдельный явно версионированный каталог доказательств, чтобы
неудачное обновление не могло сломать replay предыдущего снимка.

Повторная автономная проверка:

```sh
.venv/bin/python scripts/refresh_dataset.py --replay
.venv/bin/python -m pytest -q \
  backend/tests/test_curated_commons.py \
  backend/tests/test_named_operator_venues.py \
  backend/tests/test_wikidata_collection.py \
  backend/tests/test_poi_source_crawler.py \
  backend/tests/test_dataset_publication.py
```

Результат после публикации: replay восстанавливает 6 505 ID и то же покрытие,
SHA-256 опубликованного файла сохраняется; **130 тестов проходят**. Проверены
остановка и продолжение, исходные времена получения, неподходящие лицензии и
источники, типовые противоречия, переносимость без полного HTML, смена обложки
без потери галереи, неизменность прежних первичных полей и сохранение закрытия
исторического музея. Полный финальный прогон проекта ведётся отдельно.
