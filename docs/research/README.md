# Research overview

Current implementation: [Assistant UI and OpenUI](assistant-openui-upgrade.md), [conversational RAG and memory](conversational-rag-upgrade.md), [automated full-city POI coverage](poi-data-upgrade.md), and the [owned-key 2GIS source profile](map-api-setup.md). The latter is separate from the [embedded keyless MapLibre map](embedded-map-restoration.md). Earlier municipal and map-renderer provider experiments remain research history.

The results ruled out several weak assumptions: conversational nearby search is already offered by large products; an OSRM URL's profile label does not turn a driving graph into a pedestrian graph; full LangGraph checkpoints would retain exact locations; unverified opening hours cannot support a live-open claim; and a two-hour preflight window needs a transfer estimate before it becomes sightseeing time.

The chosen implementation prioritizes inspectable source data and deterministic constraints. Portable vectors are lexical feature hashes; prewarmed multilingual MiniLM is the current app's local neural mode. Optional cloud embeddings and model-assisted evidence/activity selection remain separate provider integrations. Independent review showed that matching source IDs cannot validate arbitrary model prose, so the model boundary accepts only approved enum selectors and renders trusted localized wording. OpenUI also uses trusted facts and a bounded component vocabulary. End-to-end tests use the actual shipped planner and corpus.
