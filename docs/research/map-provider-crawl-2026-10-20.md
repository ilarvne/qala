# 2GIS, Яндекс и Google: фактический обход и план интеграции

Первоначальная выборка этого отчёта — десять карточек. [Продолжение](map-provider-continuation-2026-10-20.md) расширяет её до шестнадцати, добавляет возобновление и очередь проверки, а также документирует отдельную коррекцию закрытого музея. [Настройка нужных API-ключей](map-api-setup.md).

Проверено 20 октября 2026 года. Выполнены поиски Exa, чтение первичной документации, обычные HTTP-запросы и посещения публичных карточек в браузере. Результат — ограниченная проверяемая выборка, а не выгрузка всех организаций Астаны. Карта Qala остаётся встроенной MapLibre/OpenFreeMap; выбор источников данных не меняет рендерер.

## Ошибки, которые обнаружил сбор

1. В одном и том же HTML 2GIS счётчики видимых вкладок и Open Graph расходятся. Для музея это 2 371 против 2 370 отзывов, для Байтерека — 3 232 против 3 228. Парсер выбирает видимый счётчик и оставляет предупреждение. Индексированный Exa фрагмент также не заменяет свежий ответ.
2. В Google рядом с Байтереком показан Baiterek Coffee с 3,8 и числом 12. Эти данные не относятся к монументу. Парсер читает только заголовок основной карточки и соседний блок рейтинга; регрессионный тест исключает подмену.
3. Google помечает совпавшую Cafela как `Мүлдем жабық` — закрытую навсегда. В локальном OSM-снимке место ещё рекомендуется, последняя правка датирована 2023 годом. Найденный исторический сайт перенаправляет на общую главную Satu и не подтверждает закрытие. Сохранён [неразрешённый конфликт](../../artifacts/provider-crawl/google/quality-conflicts.json); статус каталога не изменён. Cafellini и Coffella с другими адресами отвергнуты как другие заведения.
4. Ответ API 2GIS имеет HTTP 200, но внутри `meta.code=400` из-за отсутствия ключа. Проверка одного HTTP-кода ошибочно объявила бы такой запрос успешным.

## Что действительно дают официальные интеграции

| Источник | Подтверждённая возможность | Граница, существенная для Qala |
|---|---|---|
| 2GIS Places API | Поиск организаций и документированные поля; схема содержит статистические поля отзывов | Документация фильтров и схема неоднозначны относительно выдачи рейтингов. Фото и тексты отзывов нельзя обещать без проверки конкретной подписки. Реальный запрос без ключа отклонён |
| Яндекс Places API | ID, название, адрес, координаты, контакты, часы и признаки | В документированной схеме нет обещания рейтингов, фотографий и текстов отзывов. Обычная лицензия и расширенное хранение требуют отдельной оценки применительно к MapLibre и публичной базе |
| Google Places API | Авторизованные поля мест, фотографии и ограниченная выборка отзывов | Без авторизации получен 403. Объект Place содержит максимум 5 отзывов и 10 фото; это не API всех отзывов. Отдельно действуют правила хранения, отображения и атрибуции |
| Google Business Profile | Работа с отзывами доступных аккаунту организаций | OAuth и доступ к организациям; не анонимный экспорт города |
| Foursquare | API и договорная поставка Places, включая расширенные атрибуты по условиям продукта | Ключа/договора нет; реальное покрытие фотографий и отзывов Астаны не проверено. Самообслуживаемая лицензия ограничивает массовое скачивание и систематическое исчерпание местности |
| Geoapify | Категорийный поиск POI, географические фильтры и признаки доступности | Наличие POI API не подтверждает независимую базу пользовательских отзывов или лицензированные фото каждого места. В этой работе API не авторизован и городской результат не получен |

Первичные источники: [2GIS Places](https://docs.2gis.com/en/api/search/places/overview), [фильтры 2GIS](https://docs.2gis.com/en/api/search/places/examples/filtering), [Яндекс: ответ Places](https://yandex.com/maps-api/docs/geosearch-api/response.html), [условия Яндекса для Казахстана](https://yandex.kz/dev/tariffs/doc/ru/geosearch/terms/), [Google Place](https://developers.google.com/maps/documentation/places/web-service/reference/rest/v1/places), [Google Places policies](https://developers.google.com/maps/documentation/places/web-service/policies), [Business Profile reviews](https://developers.google.com/my-business/content/review-data), [Foursquare Data Products](https://docs.foursquare.com/data-products/docs/overview), [Foursquare EULA](https://foursquare.com/legal/terms/apilicenseagreement/), [Geoapify Places](https://www.geoapify.com/places-api/).

У публичных сайтов и официальных API разные интерфейсы и условия. Разрешённый путь в robots.txt не отменяет 429/CAPTCHA и не выдаёт право перепубликации базы. Условия [2GIS](https://law.2gis.kz/licensing-agreement/ru), [API 2GIS](https://law.2gis.kz/api-rules/ru) и [Google Maps](https://www.google.com/help/terms_maps/) рассмотрены отдельно в отчётах провайдеров. Это не вывод о запрете любого отдельного публичного факта: в текущей поставке наблюдения оставлены в исследовательском слое, а не объявлены открытой базой фотографий и отзывов.

## Встроенные виджеты

**Google проверен вживую:** обычное меню Share → Embed a map выдало iframe без API-ключа. Он отрисовал Ботанический сад с атрибуцией, рейтингом 4,6 и родным счётчиком `6,772 пікір`. Счётчик сохранён отдельно, без неподтверждённого превращения в число именно текстовых отзывов. Это то же место, а не седьмая Google-карточка. [Свидетельство](../../artifacts/provider-crawl/google/embed-frame-verification.json), [скриншот](../../artifacts/provider-crawl/google/embed-frame-proof.png), [локальная HTML-проверка](../../artifacts/provider-crawl/google/embed-proof.html), [официальная справка](https://support.google.com/maps/answer/144361?hl=en). Это потребительское встраивание отличается от требующего ключ [Embed API](https://developers.google.com/maps/documentation/embed/embedding-map).

**Яндекс: подтверждено документацией, но не живым тестом.** Официальная [справка](https://yandex.ru/support/maps/ru/concept/get-map-reference) описывает виджет отзывов из меню организации. Требуемый размер ширины 300–760 px и рекомендуемая высота от 500 px важны для мобильной карточки. После 429 виджет не запрашивался в качестве обхода ограничения.

**2GIS:** [микросайт организации](https://help.2gis.ru/question/microsites) требует её кабинета и связан с рекламным размещением; отзывы отбираются начиная с четырёх звёзд. Такой инструмент не является полной нейтральной выборкой отзывов города.

Практическое решение для следующей продуктовой интеграции: по явному открытию источника загружать официальный виджет в соответствующем диалоге, сохранять его атрибуцию и управление. Не передавать ему переписку или память предпочтений. Основная карта, маршруты и GPS остаются в MapLibre. В этом обходе создана самостоятельная проверка Google iframe; код интерфейса Qala не изменён и виджет в приложение ещё не добавлен.

## Парсеры и воспроизведение

- `scripts/providers/two_gis.py`: ограниченный парсер публичного HTML, точный firm ID, согласованность H1/OG, раздельные счётчики и обложка именно филиала. Есть CLI для локального HTML.
- `scripts/providers/yandex.py`: точный organization ID в URL, публичном объекте и URI; не переносит отзывы, авторов или сессионное состояние.
- `scripts/providers/google.py`: публичный JSON-LD либо DOM основной карточки. JS-заглушка без данных возвращает пустой результат; внутренние initialization arrays не декодируются.
- `scripts/crawl_google_public.py`: максимум шесть заранее выбранных мест, robots по наиболее точному правилу, обычная HTTP-проверка, браузерная карточка, остановка при отказе. Коды предварительного HTTP-запроса и навигации браузера записываются отдельно; неизвестный код браузера не подменяется на 200. Нет обхода CAPTCHA или смены личности после отказа.
- `scripts/providers/common.py`: единая схема, проверка точного домена и ID, конечных чисел, оригинального времени и SHA-256 свидетельства; отбрасывание секретных/signed URL и недопустимых полей.
- `scripts/audit_map_provider_crawl.py`: офлайн-сводка из сохранённых JSON. Объединяет повторные наблюдения только внутри одного провайдера и одного ID; последнее неизвестное значение не заполняется более старым.

Автоматическое сопоставление требует **точного существующего имени/алиаса и координат объекта в пределах 200 м**, а также единственности кандидата. Близость к запрошенной точке сама по себе недостаточна. Сейчас однозначно сопоставлены 5 из 10 наблюдений. Префикс «Монумент» и четыре варианта казахской латиницы оставлены для проверки; искусственные алиасы для увеличения числа совпадений не добавлялись. Повторное сопоставление идемпотентно. Коммерческие наблюдения не попадают в RAG или открытый `data/pois.json` автоматически.

```bash
.venv/bin/python scripts/audit_map_provider_crawl.py
.venv/bin/python -m pytest \
  backend/tests/test_provider_observations.py \
  backend/tests/test_two_gis_provider.py \
  backend/tests/test_yandex_public_parser.py \
  backend/tests/test_provider_google.py -q
```

Все HTML-парсеры принимают исходное время получения как `observed_at=`. Повторное чтение кэша никогда не создаёт новую дату наблюдения; без исходных метаданных время остаётся `None` с предупреждением, а общий валидатор не принимает такую строку как датированное наблюдение. CLI 2GIS требует `--observed-at` с часовым поясом. Сохранённые фактические наблюдения сохраняют исходные времена.

Проверено **75 тестов**: 32 общих, 9 2GIS, 8 Яндекс, 26 Google. Один тест запрещает сетевые соединения при выполнении офлайн-сводки; другие проверяют чужой филиал, вложенный рейтинг соседней кофейни, оригинальное время, `null`-счётчики, повторный запуск, секретные параметры ссылок и отказ браузерной страницы после успешной предварительной проверки. Это отдельный набор для новых парсеров, не повторный полный запуск приложения.

Текущий публичный корпус сохраняет **6 502 POI** и SHA-256 `5ed278ae824290ec725a730ae8e878791ac23bcfa5d2ab97cf5ee03c530e6841`. Полные ответы с сессионными данными и пользовательскими текстами остаются в приватных локальных кэшах или `/tmp`, вне архива; опубликованы минимальные факты, ссылки, даты, хеши и необходимые доказательства доступа.

## Исследовательское покрытие и следующий шаг

| Направление Exa | Успешно возвращено результатов | Уникальные URL внутри направления |
|---|---:|---:|
| 2GIS | 30 | 29 |
| Яндекс | 47 | 45 |
| Google | 42 | 40 |
| Виджеты и альтернативы | 15 | Сохранены для проверки и дедупликации |

Всего 134 поисковых результата, с повторами между направлениями. Это не 134 проверенных карточки. У 2GIS ещё 15 запрошенных результатов были отклонены схемой инструмента до выполнения поиска; они не прибавлены к успешным. Для решений использованы первичная документация и реальные ответы. [Межпровайдерные ссылки](../../artifacts/provider-crawl/cross-provider-discovery.json).

В текущем `.env` нет настроенных ключей этих картографических API. Дальнейший полный сбор требует доступного обычного сервиса либо собственного авторизованного API с проверенными правами и реальным покрытием Астаны. Для масштабирования необходимы лимит запросов, интервалы по origin, журнал остановок, проверка срока хранения и согласованный набор полей. На этой машине после CAPTCHA 2GIS и 429 Яндекса новые карточки этих провайдеров не запрашиваются.
