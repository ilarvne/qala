# Astana 3D acquisition: follow-up

Checked 19 October 2026. This is a read-only acquisition investigation, supplementing the [municipal mesh report](astana-3d-municipal.md), [open-data report](astana-3d-open-data.md) and [architecture plan](astana-3d-map-plan.md). No purchases, account changes, supplier enquiries or third-party messages were made.

## Decision

The best substantiated path to a photorealistic Astana city remains **an authorized central-area delivery of the existing municipal mesh**, through the city's Architecture and Urban Planning Department and KazAeroSpace. The city mesh already has an actual spatial streaming structure and real textures; a previous pilot decoded one available sector. The missing part is a usable and permitted central-city delivery covering the walking area, with dates, ground reference and quality evidence. Another globally marketed renderer or mesh product does not resolve that missing content.

This follow-up found a second **historically completed central-Astana photogrammetry project**, several real acquisition suppliers and some individual models. It did not find an independently qualified, publicly reusable central-Astana mesh ready for Qala. For immediate native map delivery, the earlier tested 2GIS landmark models remain the strongest verified option, subject to the project's own key. That is separate from owning a photorealistic city dataset.

Numerical accuracy in these sources is a product or service specification, not a test of this application's city model. A 3D surface raster, vector buildings, satellite mesh and oblique-aerial mesh are different deliverables. Terrain products sold through a marketplace must not be substituted for textured architectural mesh. In particular, the inspected [UP42 Vivid Terrain listing](https://docs.sa.up42.com/data/vivid-terrain) offers DSM/DTM GeoTIFF products, so that listing alone does not establish a mesh delivery.

The next acquisition comparison should request the same small central-Astana sample from each actual candidate. Compare measured silhouettes, glass-sphere geometry, lattice visibility, ground position, coverage holes and loading costs. A product label or a remote city fly-through is insufficient.

## Concrete acquisition route

1. **Municipal mesh first.** Use the existing [prepared data request](astana-3d-data-request.md) with the [Architecture/Urban Planning Department](https://www.gov.kz/org/astana-saulet?lang=ru), current portal support and KazAeroSpace. KazAeroSpace's [current contacts page](https://kazaerospace.kz/contacts) lists +7 7172 70 64 49, info@kazaerospace.com and Kerey, Zhanibek khandar Street 5/1, Astana. Ask the authority to name the imagery/mesh rights holder; do not assume the software copyright holder owns all content.
2. **Require the actual central pilot.** At minimum it must cover Bayterek, alem.ai and the relevant pedestrian streets between/around them. Ask for a coverage polygon, exact capture dates, delivered horizontal/vertical CRS, measured ground-control report, full texture/geometry hierarchy and an I3S endpoint, SLPK or 3D Tiles package. Native I3S is already a proven renderer path for one research sector.
3. **State application rights explicitly.** The needed deliverable must allow this public web application to display streamed geometry and textures, keep operational caches, use a CDN/self-hosted tiles if intended, create format/LOD derivatives, show route overlays and make demo screenshots/video. Ask for required credit and update terms. Missing rights cannot be inferred from a public portal flag.
4. **Qualify before contracting a whole city.** Accept a small representative package only after real landmark orbits and several independent ground checks pass, along with route-surface and mobile streaming checks. A sector index or broad bounding box alone is insufficient.
5. **If municipal delivery is unavailable, compare real supplier samples.** Start with Geoscan/Kazakhstan Gharysh Sapary for the historical centre archive or a new oblique survey; evaluate KazAeroSpace/KASMapping and local survey suppliers. Seek Vantor/Airbus exact AOI stock results as alternatives. A new aerial/LiDAR commission must include capture permissions, rights, control points, formats and delivery acceptance, without assuming any quoted capability is a finished dataset.
6. **Keep production honest while this is resolved.** Native 2GIS with the project's own access remains the verified immediate landmark path. A licensed Cesium mesh integration should activate only for a qualified source. The northern municipal research sector, an unavailable source prompt or a generic OSM city must not be labelled a complete accurate central-Astana map.
