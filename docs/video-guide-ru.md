# Русское демо в Remotion

`video-demo/` содержит композицию `QalaDemoRU` и семь отдельно редактируемых глав по критериям Build with AI. Видеоряд состоит из непрерывных записей работающего приложения. Презентация использует отдельные снимки.

## Финальные файлы

- `artifacts/video/ru/qala-demo-ru.mp4` — H.264, 1920×1080, 30 кадров/с, 4580 кадров, около 2:33.
- `qala-demo-ru.srt` — 70 русских субтитров по фактическому выравниванию слов ElevenLabs.
- `chapters.txt` — временные метки семи критериев.
- `youtube-description-ru.txt` — подготовленное описание. Публикация не выполнена; действительный URL YouTube отсутствует.
- `final-export-verification.json` — проверка итогового MP4: полный decode, кодеки, кадры, длительность, громкость AAC, субтитры, происхождение озвучки и индивидуальный просмотр 15 кадров из файла.

## Записи интерфейса

Семь `*-capture.webm` записаны в Chromium с реальным сервером на порту 8000. Действия, ответы API, временные маркеры, версии интерфейса и проверки находятся в `native-capture.json`. Все 41 проверки записи прошли; сводка — `browser-capture-verification.json`. В ролике показаны уточнения, сравнение, источники, диктовка, память, пошаговый маршрут, фактическая загрузка GPX и поиск по общему каталогу. Ответы приложения не подменялись.

Главы «Релевантность» и «Объяснения», а также дополнительный текущий голосовой сеанс используют `index-CS4gcpEH.js`; пять остальных записей — `index-ByLF8hAF.js`. Различие этих сборок касается кадрирования фотографий. В финальной сборке проверены шар Байтерека в карточке и полный исходный снимок в галерее. Хеши видеозаписей и границы 39 склеек находятся в `remotion-edit-manifest.json`. Задержки убраны, фрагменты синхронизированы с речью; ролик не измеряет скорость ответа приложения.

`voice-current-capture.webm` — отдельная непрерывная запись одного текущего сеанса после обновления приватной конфигурации. SDK действительно подключился, отобразились русские сообщения, после примерно 32 секунд сеанс явно завершён. Поданы синтетические данные виртуального микрофона Chromium; физический микрофон и телефонный звонок не проверялись. Полного ответа инструмента планирования в этом сеансе не наблюдалось, поэтому запись не доказывает изменение маршрута голосовым разговором. Подробности — `voice-current-capture.json`. Историческое видео разговора от 19 октября в финальном монтаже полностью исключено.

Выбор 16 разговорных языков записан в текущем интерфейсе. Все 16 пресетов настроены и считаны обратно из ElevenLabs, выдача приватной сессии проверена; 16 живых разговоров не проводились. Интерфейс и внутренний план остаются EN/RU/KK. Диктовка AlemPlus — отдельная функция; в записи она получила реальный ответ распознавания и передала текст планировщику.

## Новая русская озвучка

Финальные семь дублей созданы на ElevenLabs `eleven_v4`, голос Sarah, `language_code=ru`, с нативными временными метками. Текст содержит 2080 символов: короткие фразы, числа словами, без произносимых названий библиотек. Сначала проверен 178-символьный пробный дубль: реальное распознавание AlemPlus воспроизвело все проверяемые слова, MP3 полностью декодировался. Затем проверены все главы: HTTP 200 от STT, полный decode, сходство слов 97,5–100%; две разницы касаются окончаний, пропущенных разделов нет. Это проверка разборчивости и содержания, а не оценка произношения носителем языка. Человек не подтверждал качество акцента.

Русскоязычный голос из библиотеки удалось добавить, однако единственная попытка синтеза была отклонена HTTP 402. Повторов и платного обновления подписки не было; использован доступный голос Sarah на v4. После проверки содержания один дубль памяти пересоздан с точной фразой «Точная геопозиция и переписка в эту память не входят»: округлённый `coarse_location` может храниться среди предпочтений. Остальные шесть новых дублей повторно взяты из проверенного кэша.

Доказательства:

- `voice-audition-v4/sample-review.json` — пробный дубль, реальный STT и границы проверки.
- `narration-generation-v4.json` — полный чек семи текущих дублей, шесть из кэша и один исправленный HTTP 200, хеши запросов и аудио.
- `artifacts/history/narration-generation-v4-before-privacy-qualifier.json` — исходные семь фактических генераций v4, к которым привязаны шесть кэшированных дублей.
- `artifacts/history/narration-generation-v4-privacy-corrected.json` — неизменяемый чек реальной генерации исправленного дубля памяти; позволяет проверить его при дальнейшем чтении из кэша.
- `narration-v4-transcription-verification.json` — фактическое распознавание всех семи текущих MP3, включая исправленный дубль памяти.
- `*-alignment.json`, `*-elevenlabs.mp3` — тексты, временные метки и звук. Нормализованные WAV находятся в `video-demo/public/media/`.

## Повторный экспорт

Новая генерация речи для сборки уже подготовленного проекта не нужна:

```sh
cd video-demo
npm ci
npm run dev -- --no-open
```

Откройте `http://localhost:3000/QalaDemoRU`. Сцены доступны по отдельности; каждый из 39 фрагментов — отдельный узел JSX с редактируемыми границами. Субтитры записаны прямо в исходниках сцен.

Из корня проекта:

```sh
python scripts/render_demo_ru.py --detach --concurrency 4
```

Состояние и хеши исходников сохраняются в `render-process.json`. Не запускайте второй экспорт в тот же файл и не меняйте исходники до завершения. FFmpeg нормализует и проверяет звук; финальный монтаж и экспорт выполняет Remotion.

После экспорта:

```sh
python scripts/verify_demo_ru.py
# Просмотреть каждый из 15 кадров final-export-frames/.
python scripts/verify_demo_ru.py --confirm-visual-review
```

Подтверждение допустимо после просмотра всех кадров из фактического MP4. Пакетировщик сверяет отчёт с хешем видео и не принимает незавершённый или изменившийся экспорт.

Для намеренного изменения озвучки есть `scripts/generate_narration_v4.mjs`: он читает только приватный `.env`, поддерживает пробный дубль и полную генерацию, не повторяет платные запросы после ошибки и сохраняет чеки. Перед заменой дублей нужно сохранить исходные чеки реальных генераций. `prepare_remotion_demo.py --media-dir artifacts/video/ru --refresh-captions --require-video` переносит проверенные материалы; `author_russian_edit_v4.mjs` задаёт текущие авторские склейки по нативным меткам слов. При новой записи интерфейса интервалы источников проверяются заново: старые границы нельзя переносить автоматически.

## Границы данных

В исходном каталоге 6505 точек; карта исключает закрытый объект. Фотографии, часы, оценки и отзывы показываются там, где есть доступный источник. Ответы 2GIS запрашиваются при открытии карточки и не сохраняются в набор POI; доказательства записи содержат HTTP-статусы без тел ответов поставщика. Лицензии фото и исходные ссылки доступны в карточках и документации источников.

В первом сценарии явно симулируется GPS у Mega Silk Way; местоположение физического устройства не проверялось. Карта MapLibre/OpenFreeMap встроена в приложение, объём зданий схематичен и не является фотограмметрией или проверенной моделью достопримечательностей. Текущие API и правила хранения описаны отдельно; видеоролик не заменяет эти исходные доказательства.
